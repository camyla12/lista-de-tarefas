# Lista de Tarefas

Projeto desenvolvido com HTML, CSS e JavaScript para organizar atividades do dia a dia.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Adicionar tarefas.
- Marcar tarefas como concluídas.
- Excluir tarefas.

## Como executar

1. Baixe os arquivos do projeto.
2. Abra o arquivo `index.html` no navegador.
3. Digite uma tarefa.
4. Clique em Adicionar.
5. Utilize os botões para concluir ou excluir tarefas.

## Objetivo

Projeto desenvolvido para praticar conceitos básicos de desenvolvimento web.
